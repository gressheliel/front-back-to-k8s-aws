## Instalaciones
- Referencia para instalar NodeJS en instancia EC2
  - https://docs.aws.amazon.com/sdk-for-javascript/v2/developer-guide/setting-up-node-on-ec2-instance.html
- Ejecutar los siguientes comandos en la instancia EC2
  - sudo su
  - curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  - source ~/.bashrc
  - nvm install --lts
- Probar la instalación
  - node -e "console.log('Running Node.js ' + process.version)"
  - Salida : Running Node.js v24.11.1

## Crear pipeline de CI/CD en Jenkins para Aplicación Angular
- Agregar el plugin de NodeJS en Jenkins
  - Manage Jenkins -> Plugins -> Available Plugins -> Buscar "NodeJS" -> Install without restart
- Agregar como herramienta NodeJS en Jenkins
  - Manage Jenkins -> Tools -> NodeJS Installations -> Add NodeJS -> Name: NodeJS -> 
  - Version : 24.11.1 -> Save
  - Es la misma version que se instaló en la instancia EC2
