## ArgoCD - Continuous Delivery para Kubernetes
- http://argo-cd.readthedocs.io/en/stable/getting_started/

- ArgoCD es una herramienta de Continuous Delivery para Kubernetes que permite implementar aplicaciones de manera 
- automática. Se integra con repositorios Git para sincronizar el estado deseado de las aplicaciones con el estado 
- actual en el clúster de Kubernetes.

## Pre-condiciones
- Tener un clúster de Kubernetes en funcionamiento (EKS, Minikube, etc.)
- Tener kubectl instalado y configurado para acceder al clúster de Kubernetes.
- Tener acceso a un repositorio Git donde se almacenarán los deployments(Manifest de kubernetes) de las aplicaciones.

## Instalación de ArgoCD
- Crear el namespace para ArgoCD
  - kubectl create namespace argocd
- Instalar ArgoCD en el clúster de Kubernetes
  - kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
- Port-forwarding del servidor de ArgoCD para acceder a la interfaz web
   - kubectl port-forward svc/argocd-server -n argocd 8080:80
   - Acceder a la interfaz web en http://localhost:8080

## Instalación la CLI de ArgoCD
  - chocolatey install argocd-cli

## Obtener la contraseña inicial
  - argocd admin initial-password -n argocd
  - (admin, <contraseña_obtenida>)

## Generar llaves privada y publica
- Generar un par de llaves SSH para la autenticación entre ArgoCD y el repositorio Git
  - ssh-keygen -t rsa -b 4096  [Desde la powershell, como administrador] 
  - Public Key: Para GitHub
  - Private Key: ArgoCD en localhost
  - Guardar en: C:\Users\<usuario>\.ssh\argocd_rsa 

## Agregar llave publica en git
- En gitHub, desde la cuenta de usuario, ir a Settings -> SSH and GPG keys -> New SSH key
- Title: ArgoCD Key
- Key type: Authentication key
- key: <Pegar la llave pública generada>
- Click en Add SSH key

## Agregar llave privada en ArgoCD
- Configurar un WebHook en el repositorio Git para notificar a ArgoCD sobre cambios en los deployments.
- Settings -> Repositories -> Connect Repo ->
  - Via SSH
  - Name:
  - URL: git@github.com:gressheliel/front-back-to-k8s-aws-deployment-cicd.git
  - SSH Private Key: <Pegar la llave privada generada>
- Click en Connect

## Aplicar el deployment de la aplicación
- Crear un archivo YAML para definir la aplicación en ArgoCD (application.yaml)
- Modificar los valores según sea necesario
  - git-branch, repoURL, path.
- Aplicar el archivo YAML para crear la aplicación en ArgoCD
  - kubectl apply -f application.yaml -n argocd
```
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: restaurant-listing-default
  namespace: argocd
  annotations:
    argocd-image-updater.argoproj.io/image-list: myalias=docker.io/codedecode25        
    argocd-image-updater.argoproj.io/write-back-method: git:secret:argocd/git-creds           
    argocd-image-updater.argoproj.io/git-branch: master                                          
    argocd-image-updater.argoproj.io/myalias.force-update: "true"
spec:
  destination:
    server: 'https://kubernetes.default.svc'
    namespace: default
  source:
    repoURL: 'git@github.com:udemy-dev-withK8s-AWS-codedecode/deployment-folder.git'
    path: ./aws
    targetRevision: HEAD
    directory:
      recurse: true
  project: default
  syncPolicy:
    automated:
      selfHeal: true
    syncOptions:
      - Validate=true
```
